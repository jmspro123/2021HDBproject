Project Objective

This project addresses a common real-estate problem: understanding which variables most strongly influence pricing and how accurate predictions can be when using structured property data. By modeling Singapore HDB resale prices, the analysis demonstrates the kind of business-facing analytics work expected in modern data science roles.

Feature Analysis Predictive Modeling Business Insight Statistical Learning

Why It Matters

Housing is one of the most critical financial decisions in Singapore. Understanding the drivers of resale prices provides insight into market behavior, supports decision-making, and shows how data science can be used to extract value from real-world datasets.

Methodology

Exploratory Analysis Reviewed distributions, summary statistics, and relationships between housing attributes and pricing.
Unsupervised Learning Used PCA and clustering techniques to uncover data structure and segment market patterns.
Regression Modeling Compared linear regression, polynomial regression, and KNN regression for price prediction.
Classification Applied logistic regression and decision trees to predict whether a flat sits above the median price threshold.

Key Takeaways

  • ✓Property size, distance to the CBD, and remaining lease duration had strong relationships with price.
  • ✓Strong model performance suggests the project is not just descriptive, but genuinely predictive.
  • ✓The project highlights practical data science skills: feature engineering, validation, and model interpretation.
